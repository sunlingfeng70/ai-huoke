# 判定只看评论文本，排除档主要靠人工标注

模型判定意向档时能看到的证据只有评论者的**昵称**和他名下**全部评论的文本**，系统不额外拉取评论者的个人主页。因此「排除」这一档主要由人工在名单上标注，模型只在评论者自己说漏嘴时（「我也在做 AI 培训」）才会主动判出。

这么做是因为取数层（`xhs-new-search` 的 `fetch_comments`）每条评论只返回评论ID、用户昵称、用户ID、评论内容、发布时间、点赞数、回复数和子评论——没有简介、没有粉丝数、没有历史笔记。而「排除」定义中的同行、竞品、从业者身份恰恰写在个人主页里，不写在评论里：同行在评论区往往只留一句「讲得好」，从文本看与路人无异。要判准就必须为每个候选评论者额外请求一次主页，一批几百人就是几百次请求，风控面显著变大，换来的却是人工点开主页一眼就能得出的结论。高意向、潜在意向、不相关三档不受影响，它们本就该从评论文本判断。

代价是人工标注从「锦上添花」变成了**系统的必要组件**：没有回流入口，排除档就是一个模型永远猜不准、又无法被纠正的档位。好处是标注一次永久生效，不像每批重跑的模型判断那样会反复出错。若两周后发现模型漏掉的同行多到人工标不过来，再考虑补上主页取数——那时有真实的漏判数据可依据，比现在凭空决定强。
