# 只读边界：系统不代替人触达

获客系统从小红书**只读取**数据（搜索笔记、拉取评论），产出排序后的意向名单和建议话术；实际的私信、回评等触达动作全部由人工在小红书 App 内完成。

这么做的原因是风险与收益极不对称。小红书自 2025-01-07 起将「私信获客工具」定为交换联系方式的唯一合规路径，且仅认证企业号与绑定企业 KOS 的个人专业号可用；主动向陌生人打招呼上限 20 次/天；评论区或私信中出现联系方式（含 `VX`、`威❤` 等变体）按《交易导流违规管理细则》处罚，从删帖警告到 7/14/30 天禁言乃至永久封号，教育培训被官方点名为需格外注意的类目。而 AI 能创造的价值几乎全在「判断哪条评论是高意向」这一步——自动化「点击发送」只省下以秒计的时间，却要拿主账号存续去赌。

因此系统不持有任何小红书写权限。若日后要做自动触达，须先认证企业号并接入官方私信获客工具，而非逆向写操作接口——那会是一个新的决策，需要新的 ADR。
