# 每批重判全部线索，不设升档规则

每批采集时，把每位评论者**至今为止的全部评论**（历史 + 本批新增）一起交给模型，重新得出意向档。没有「潜在意向 + 新增 N 条评论 → 升为高意向」这类显式规则。名单里显示上一批的档位，档位变化时标出来（如「潜在意向 ← 上批高意向」），不静默改写。

这么做是因为「升档」在 ADR-0002 的前提下不是一个需要实现的功能，而是重判的副产品：判断单位已经是评论者，每批都拿全部评论重判，档位自然随证据增长而变化。显式升档规则要凭空指定 N，还会覆盖模型的判断——新增的两条评论可能只是「哈哈哈」。重判同时顺手解决了反向情况：之前判高意向若是模型看错，重判会自然修正，而升档规则是单向的，修不回来。

两个代价。一是每批要为所有历史线索重跑模型判定，token 成本随线索累积线性增长——到几千条线索时这个决策值得重新审视。二是档位会**自己抖动**：模型不是确定性的，同一个人这周高意向下周潜在意向。缓解办法是把上一批档位和变化痕迹显示在名单上，让人看得见变动而不是被静默改掉；但抖动本身消除不了，这是接受重判换来修正能力的代价。
