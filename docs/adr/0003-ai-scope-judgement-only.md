# 只做意向判断，不做关键词自扩展

「AI 原生」在本项目中只落在一处：把某位评论者的全部评论交给模型，输出意向档、判定理由和开场白。搜索关键词由人工给定，系统不自行扩展搜索面。

曾考虑让系统根据「高意向线索都出现在哪些笔记下」反推下一批该搜什么词，使关键词成为产出而非输入。放弃的原因是这套反馈依赖「哪些线索最终成交」的回流信号，而项目起步时一条线索都还没有——没有正反馈，关键词自扩展只是让模型编造同义词，效果未必优于人工选词。

但归因字段（来源关键词、来源笔记）从第一天就记录，因为它不可逆：小红书的 `xsec_token` 会过期、笔记会被删，采集当时没记下来的来源，事后无法重建。这样日后若要重启关键词自扩展，历史数据是可用的。
