# AI 原生获客

从小红书笔记的评论中识别想学 AI 的人，产出可供人工触达的意向名单。自用单租户，服务于「卖 AI 课程」这一个业务。

**当前状态：骨架已通，尚未接真实数据。** 取数与判定都还是假实现，跑起来能看到一份结构完整的名单，但内容是写死的示例。

## 它做什么

给一个来源关键词，把该关键词下笔记的评论全部取回来，按评论者聚合，交给模型判出意向档，产出一份按意向档排序的 Markdown 名单。名单上每条线索带着判定理由（便于审查模型判得对不对）、开场白草稿、归因和用户ID。

**系统只读，不代替人触达。** 私信、回评全部由人工在小红书 App 内完成。原因见 [ADR-0001](docs/adr/0001-read-only-no-automated-outreach.md)——小红书对交易导流的处罚从删帖到永久封号，而 AI 能创造的价值几乎全在「判断哪条评论是高意向」这一步。

## 跑起来

```bash
python3 huoke_cli.py "AI入门"
```

产出 `AI入门_leads.md`。目前用的是假数据，不联网、不需要 Cookie 或模型 key。

## 名单长什么样

```markdown
# AI入门

## 高意向

**想转行的小张** (`u_eager`)

**判定理由**：明确说「零基础想学，有推荐的课吗」，直接求课程推荐。

**开场白**：看到你想从零开始学 AI，方便聊聊你的基础和目标吗？

**归因**：来源关键词 `AI入门`
- 搜索「AI入门」的示例笔记 A — https://www.xiaohongshu.com/explore/demo_a
```

用户ID 显式打出来，是为了让人能复制它到排除名单文件里（见 [ADR-0006](docs/adr/0006-exclusion-list-as-plain-text.md)）。

## 四个意向档

| 意向档 | 含义 | 在名单里 |
|---|---|---|
| 高意向 | 明确表达想学、求推荐、问怎么入门 | 排在最前，优先触达 |
| 潜在意向 | 有兴趣但表述模糊（「码住」「求教程」） | 留着，评论增多后可能升为高意向 |
| 不相关 | 玩梗、灌水、与 AI 学习无关 | 不占篇幅 |
| 排除 | 同行、竞品、已具备进阶能力的从业者 | 显示出来供人工核对后标注，永不触达 |

「排除」是唯一主要靠人工标注而非模型判定的档位——同行在评论区往往只留一句「讲得好」，从文本看与路人无异，判准就得为每个候选拉一次主页，几百人就是几百次请求。所以模型只在评论者说漏嘴时判出，其余靠人看一眼昵称点开主页，标一次永久生效。详见 [ADR-0005](docs/adr/0005-exclusion-is-human-marked.md)。

## 设计约束

判断单位是**评论者**，不是单条评论。「求教程」孤立看只是模糊信号，但同一个人在五条 AI 笔记下都这么留言，画像就完全不同（[ADR-0002](docs/adr/0002-commenter-as-lead-unit.md)）。

每批采集都基于该评论者**至今全部评论重判**，没有独立的升档规则。档位的上升与下修都是重判的自然结果（[ADR-0008](docs/adr/0008-rejudge-every-batch.md)）。

**归因必须在采集当时落库**——`xsec_token` 会过期、笔记会被删，事后无法重建（[ADR-0003](docs/adr/0003-ai-scope-judgement-only.md)）。

取数层是 `xhs-new-search` 技能里的脚本，通过**子进程**调用而非导入。它模块级调用 `_bootstrap()`，在缺 `xhshow` 时会用 `os.execv` 把调用方进程整个替换掉——导入会劫持调用方，在 pytest 里会把测试进程自己 exec 掉（[ADR-0009](docs/adr/0009-fetch-layer-via-subprocess.md)）。

模型走 OpenAI 兼容的 HTTP 接口，端点与模型名从环境变量读（[ADR-0010](docs/adr/0010-openai-compatible-http-via-env.md)）。

## 开发

目标解释器是系统 Python 3.9.6，所以每个模块都要在用 `dict[str, str]` 这类注解前写 `from __future__ import annotations`。

```bash
python3 -m venv .venv && .venv/bin/pip install pytest   # 首次
.venv/bin/pytest                                        # 全量
```

批次管道把取评论和判定都做成函数参数，所以整个测试套件不联网、不需要模型 key。
